Pasos para ejemplo de verificacion de memora con osvvm

1- crear el pkg con las constantes de tamaño de buses
2- crear el bfm con los procedures ramwrite y ramread
3- crear el test creando una entidad (igual que la del rtl) y usando el memoryPkg y el AlertLogPkg.vhd de osvvm
4- crear el tb instanciando la entidad del dut y la del test
5- ejecutar los scripts tcl necesarios para el simulador de OsvvmLibraries/Scripts/
    en este caso en el compile.do se coloca
    source "$OSVVM_SCRIPT_DIR/StartQuesta.tcl"
    source "$OSVVM_SCRIPT_DIR/VendorScripts_Questa.tcl"
    source "$OSVVM_SCRIPT_DIR/StartUp.tcl"
6- agregar en la compilacion el script osvvm.pro ubicado en OsvvmLibraries/osvvm/
    este archivo se encarga de compilar laqs librerias de osvvm (MemoryPkg.vhd, MemorySupportPkg.vhd. AlertLogPkg.vhd entre otros)
7- crear el directorio de simulacion y compilar los rtl alli y simular
